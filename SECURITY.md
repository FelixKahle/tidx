# Security

## Supported versions

The latest published version of `tidx` receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability, such as a way to reach undefined behaviour through the safe
API. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/FelixKahle/tidx/security/advisories/new).

You can expect a first answer within a week. A confirmed vulnerability is fixed in a new release, and the affected
versions are yanked from crates.io.
